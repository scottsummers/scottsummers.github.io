How to play Snake

  • Steer with the arrow keys or WASD, or swipe and use the arrow pad on a touch screen.
  • Eat apples (+1) to grow. A gold star sometimes appears for a few seconds and is worth +5. Grab it before it fades!
  • Don't run into yourself. In Walls mode the edges are deadly too; in Wrap mode you come out the other side.
  • Obstacles mode adds blocks to dodge. Turbo is fast. Each mode keeps its own best score.
  • Space or P pauses. The game pauses itself if you switch tabs.
